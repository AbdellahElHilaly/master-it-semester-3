# PAR Basics — أساسيات البرمجة المتزامنة والمتوازية

This folder is the first learning-by-doing unit for the PAR module.

## What you will learn

- The difference between sequential execution and concurrent execution.
- The meaning of **process**, **thread**, **task**, and **shared resource**.
- How to create Java threads and wait for them with `join()`.
- How to compare a sequential solution with a concurrent one.

## Run the examples

From this folder:

```powershell
javac code\ThreadBasics.java code\SequentialVsConcurrent.java
java -cp code ThreadBasics
java -cp code SequentialVsConcurrent
```

You need a JDK installed. The examples use standard Java only; no external library is required.
